Overview
This is a single-file, zero-dependency, pure C++ Transformer implementation. It is specifically designed for on-device training and inference on Android devices (Termux) using nothing but the CPU.
All forward and backward propagations are hand-written. No PyTorch. No TensorFlow. No external ML frameworks.

Architecture (Modern LLM Skeleton)
It implements the core backbone of modern LLMs (e.g., LLaMA 3, Qwen):
*   Decoder-only causal language model
*   Character-level Tokenizer
*   RoPE (Rotary Position Embedding)
*   RMSNorm (Pre-Norm)
*   GQA (Grouped Query Attention)
*   QK-Norm (Stabilizing attention scores)
*   SwiGLU (Gated feed-forward network)
*   KV Cache (For fast autoregressive inference)
*   AdamW with Warmup & Cosine learning rate scheduling

Real-World Results on Mobile
Tested on a MediaTek Dimensity 6300 (8-core CPU). It demonstrates true generalization beyond the training set:
*   0-9 Addition: ~55k params. Learned carries. Perfect accuracy on unseen combinations.
*   4-Turn Chat: ~640k params. Learned turn-taking and state transitions. Handles out-of-distribution turn sequences.
*   String Reversal: ~730k params. Trained on 4,000 random strings (length 1-8). Perfectly reversed unseen combinations (e.g., Input QwErTy -> Output yTrEwQ) by learning the positional reversal rule, not by memorization.

Quick Start

1. Environment Setup (Termux)
pkg update && pkg upgrade -y
pkg install clang make git python -y

2. Compile
clang++ -O3 -march=armv8.2-a+dotprod -ffast-math -fno-math-errno -funroll-loops -fomit-frame-pointer -fno-exceptions -fno-rtti -o tiny tiny.cpp

(Note: If your device does not support the -march flag, just remove it.)

3. Run the Demo
The run.sh script will automatically generate the string reversal dataset, compile the code, train the model, and test it.

bash run.sh

Or run manually:
# Train
./tiny --mode train --data data.txt --model tiny.bin --D 128 --L 4 --nq 4 --nkv 2 --ctx 48 --epochs 100 --batch 16 --lr 1e-3 --stop-loss 0.02

# Inference
./tiny --mode gen --model tiny.bin --prompt "<u>Hello<a>" --greedy
